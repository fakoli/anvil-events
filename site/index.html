One event. Every subscribed node. Converged.

An authority declares exact desired bytes once. Each healthy node catches up on its own schedule, applies only the resource it owns, verifies the observed result, and publishes a correlated outcome.

01 / LOCAL FIRST

The network is never your transaction.

Recording an event commits intent, identity, sequence, and pending delivery together in SQLite. Publication happens asynchronously.

02 / NARROW AUTHORITY

Events carry intent, not capabilities.

Private node manifests own paths, credentials, commands, and the exact producer/resource/adapter bindings allowed to apply automatically.

03 / HONEST RECOVERY

Unknown side effects stay unknown.

If a process dies after apply begins, the attempt is indeterminate. It is never silently replayed behind an “exactly once” promise.

A convergence system, not a remote shell.

The event bus announces a desired generation and binds it to immutable content. Every authority-bearing detail remains local to the node.

The event namesA logical resource, generation, immutable revision, SHA-256 digest, adapter, artifact reference, and optional target nodes.
The node ownsReal destinations, artifact origins, credential references, validation commands, rollback behavior, and automatic-apply policy.
The adapter doesPreview, apply, verify, and rollback for exactly one bounded integration seam.
The journal provesWhat was accepted, delivered, attempted, observed, and reported—without upgrading those facts into a global side-effect guarantee.

The guarantee has edges.

Those edges are part of the product contract, not footnotes.

What is guaranteed

  • Atomic, idempotent local acceptance
  • At-least-once broker delivery after PubAck
  • Fail-closed event and generation identity
  • Serialized reconciliation per node resource
  • Verification before an applied outcome
  • Eventual convergence after faults stop and policy permits

What is not claimed

  • No fleet-global sequence
  • No globally exactly-once external side effects
  • No automatic shell, Git, or arbitrary path execution
  • No trust derived from network reachability alone
  • No health claim from configuration status alone
  • No finite broker retention without a tested snapshot path

Small modules. One runtime.

The v0.2 redesign separates the contracts that used to be tangled together, while preserving one dependency-free artifact.

domain_v2

Canonical envelopes, bounded payloads, identity, subjects, and desired-state vocabulary.

storage/

SQLite transactions for events, PubAck evidence, operations, reconciliation generations, facts, retention, and migration.

transport/

NATS framing, JetStream publishing and durable pulls, verified TLS, authentication, and subject validation.

reconciliation/

Artifact resolvers, exact policy bindings, adapter registry, resource locking, preview/apply/verify/rollback, and durable outcomes.

runtime/

Composition, asynchronous delivery, subscription, startup repair, health semantics, and the optional artifact publisher.
