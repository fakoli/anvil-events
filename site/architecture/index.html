Architecture

anvil-events separates immutable history from desired-state convergence.

Mental model

An authority does not send a command to a host. It records an immutable state.desired event that names a resource generation and the exact bytes that generation represents. The broker retains the event. Each subscribed node makes a local decision—using its own manifest, policy, adapter, and credentials—then records what happened.

Intent crosses the network. Capability does not. Events can name logical resources and immutable artifacts. They cannot choose local paths, executables, argument prefixes, secrets, or network endpoints.

This split keeps the public product generic. A portable node configuration describes adapter shapes with synthetic identities; real topology and authority bindings stay in an operator-owned private deployment repository.

Data flow

  1. Accept locally. record validates the v2 payload and commits the idempotency key, operation row, producer sequence, canonical envelope, and pending-delivery state in one SQLite transaction.
  2. Publish asynchronously. The delivery pump scans indexed pending rows, publishes with Nats-Msg-Id=event_id, and accepts completion only from a positive PubAck naming the configured stream.
  3. Pull durably. Each node binds a named JetStream durable consumer. Disconnection leaves unacknowledged messages available for redelivery.
  4. Validate before journaling. The subscriber checks the envelope, producer allowlist, actual broker subject, and canonical identity. Invalid input is dropped without entering reconciliation.
  5. Journal before processing. A valid delivery is appended idempotently to the local SQLite journal before any adapter runs.
  6. Claim one generation. A cross-process resource lock and a transactional reconcile claim serialize one resource. Lower generations are superseded; conflicting reuse fails closed.
  7. Resolve and preview. The node loads the manifest-selected adapter and exact artifact, verifies revision and SHA-256, then creates a bounded preview.
  8. Apply under policy. Automatic apply requires the exact (authority producer, resource, adapter) binding. Otherwise the delivery stays unacknowledged as awaiting approval.
  9. Verify, classify, report. Verified state records reconcile.applied. Verification failure attempts rollback. An apply exception becomes indeterminate. The correlated outcome is itself durably recorded for delivery.
  10. ACK last. The subscriber acknowledges the broker message only after durable local processing has reached a classified result.

The four boundaries

Domaindomain_v2.py defines canonical JSON envelopes, producer-scoped identity, resource generations, bounded payloads, and the desired/outcome vocabulary. V1 remains readable only for migration.
Storagestorage/ composes focused repositories over one SQLite database: events, delivery evidence, operation intent, reconcile attempts, queries, facts, retention, and fail-closed legacy import.
Transporttransport/ implements the NATS wire contract directly with the standard library: framing, JetStream APIs, verified TLS, authentication, endpoint policy, PubAck parsing, and subject validation.
Reconciliationreconciliation/ owns artifact resolution, adapter and policy protocols, generation state, cross-process locking, and preview/apply/verify/rollback orchestration.

Runtime composition

EventsService is the composition root. It opens the store, optionally loads a node reconciler, starts the subscriber and delivery pump, and exposes bounded loopback health. Native services and the container execute this same code path.

Built-in adapters

  • Managed file: atomically owns and replaces one complete secret-free file.
  • JSON merge: applies an RFC 7396-style object patch while preserving unmentioned fields and rejecting protected or credential-shaped paths.
  • Command config: invokes one manifest-fixed executable with argv only. Events may provide values only for an explicit non-secret key allowlist.

Consistency model

anvil-events deliberately has no fleet-global clock. Two scoped orders are sufficient:

  • producer_seq identifies program order for one producer.
  • generation orders desired state for one logical resource authority.

Unrelated resources may be observed in different orders on different nodes. For one resource, a node applies only a generation greater than its durable observed generation. The same identity or generation with different canonical content is equivocation and aborts.

Timestamps are diagnostics. They never decide authorization, generation precedence, or whether an adapter may apply.

Failure recovery

Producer offline

The event remains pending in SQLite. The delivery pump retries with bounded backoff. A later matching PubAck atomically records broker evidence and advances the producer cursor.

Consumer offline

JetStream retains history indefinitely by default. The durable consumer resumes unacknowledged delivery when the node returns, including nodes enrolled after the desired event was published.

Poison local data

Malformed or non-canonical pending rows are quarantined, removed from delivery work, and surfaced through a journal-only degradation event. They cannot block the rest of the queue silently.

Crash during apply

A durable applying row exists before the external side effect. If startup finds it abandoned, the attempt becomes INDETERMINATE and requires explicit operator recovery. Startup also re-verifies previously applied resources and repairs drift when the exact desired artifact still resolves.

Security boundaries

  • Fleet transport cannot downgrade: fleet mode requires tls://, server-name verification, and authentication. Plaintext is restricted to loopback development boundaries.
  • Identity is layered: broker ACLs bind a principal to a subject prefix; the envelope producer must belong to its node; the subscriber checks the actual broker subject against the envelope subject.
  • Desired payloads are inert: credential-shaped keys, URLs, unsafe identifiers, and oversized or deeply nested JSON are rejected.
  • Artifact access is explicit: the optional publisher is authenticated, read-only, loopback-only HTTP intended to sit behind separately managed private HTTPS ingress.
  • Health is narrow: /live proves local store/workers, and /ready adds broker connectivity. Neither proves an external application accepted or reloaded configuration.

One artifact, two runtimes

The package exposes one serve runtime. Portable templates wrap it as a macOS launchd daemon, Linux systemd unit, or a thin container. The SQLite root remains host-durable in every shape.

Public deployment files are examples, not topology. Installation, real manifests, credentials, service selection, rollout, and live acceptance are separate operator actions.
